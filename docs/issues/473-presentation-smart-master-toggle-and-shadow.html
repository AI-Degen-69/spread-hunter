כפתור אחד חכם ששולט גם במסחר חי וגם בריצת אימון

קודם: מסך הניהול ידע להפעיל רק מסחר חי עם כסף אמיתי, וריצות אימון הצריכו פקודות ידניות.
עכשיו: הכפתור הראשי מזהה בעצמו איפה אתם נמצאים ומפעיל בדיוק את הריצה הנכונה — בלי לערבב ובלי לסכן אגורה.

הדגמה חיה: ראו איך הכפתור משתנה לפי המצב

בחרו מצב צפייה ולחצו על הכפתור כדי לראות את ההתנהגות וההגנות בפעולה:

מצב נוכחי במסך: מסחר חי (Live Orders)
בסיס נתונים: data/orders.db
הפעלה כוללת של המסחר
מפעיל את כל שירותי המסחר החי ברקע
שירותי מערכת ומצב נעילה:
סורק שווקים (Scanner) פעיל
מנוע עסקאות (Trader) מוכן לפקודה
●
מצב מסחר חי: לחיצה על הכפתור מפעילה את הבוט בזירה האמיתית. הכפתור ירוק, והפקודות מגיעות ישירות לחשבון.

מה השתנה במערכת?

הבדל ברור בין הגרסה הקודמת לגרסה הנוכחית:

לפני השינוי

  • הכפתור הראשי ידע רק לשלוח פקודות מסחר חי.
  • כשצפית בריצת אימון, הכפתור הראשי היה מנוטרל או חסר שימוש.
  • כדי להריץ אימון היה חובה לפתוח חלון שחור ולהריץ פקודה טכנית.
  • חשש מתמיד שלחיצה בטעות תפעיל כסף אמיתי בזמן צפייה באימון.

עכשיו (מעודכן)

  • זיהוי חכם: הכפתור מזהה מיד אם מביטים במסחר אמיתי או באימון.
  • הפעלה בלחיצה: אפשר להפעיל ולעצור ריצת אימון ישירות מהמסך.
  • הגנת ברזל: בצפייה באימון, כל שירותי המסחר האמיתיים ננעלים (LIVE ONLY).
  • אפס סיכון: ריצת האימון רצה ללא מפתח חתימה ואף פעם לא נוגעת בקובץ הכסף האמיתי.

איך תבדקו את זה ישירות במערכת?

בלי בדיקות קוד, פשוט לפתוח את המסך ולראות:

  1. מפעילים את מסך הניהול: python -m dashboard.server
  2. פותחים את הדפדפן בכתובת: http://127.0.0.1:8799
  3. מביטים בכפתור הראשי למעלה — הוא ירוק וכתוב עליו START RUN.
  4. עוברים בתפריט העליון לתצוגת קובץ אימון (למשל קובץ שדו) — הכפתור הופך אוטומטית לסגול ורושם START SHADOW!
  5. לוחצים עליו — הכפתור מתחלף לענבר ורושם STOP SHADOW, וריצת האימון מתחילה ברקע בבטחה.
