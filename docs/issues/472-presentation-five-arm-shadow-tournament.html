חמש גישות להצבת מחיר על אותו שוק, בלי כסף אמיתי

לפני: לא היה ידוע איזו גישת הצבת מחיר מתמלאת יותר טוב — רק תיאוריה על נייר.
עכשיו: חמש גישות רצות יחד באימון, כל אחת בשוק הזמנות משל עצמה, ובסוף מקבלים ספירה לכל גישה.

● נסו בעצמכם: כמה רחוק כל גישה עומדת כשהשוק רועד

4.0

הזיזו את הסליידר. כל שורה היא גישה; הקו האנכי הוא מקום ההזמנות בשוק, והפס מודד כמה סנטים הגישה מתרחקת אחורה מהשוק. השורות מסודרות מלמעלה (קרובה) ללמטה (רחוקה). קריאת התוצאה: רחוקה יותר = מתמלאת לאט ובמחיר זול, אבל כמעט לא קונה כלום. קרובה יותר = מתמלאת מהר ובמחיר יקר, עם סיכון גבוה שרק רגל אחת תתמלא.
כלומר "שמרנית" כאן פירושה סבלנית במילוי — לא שמרנית במחיר. זו בדיוק הנקודה שתחרות האימון באה למדוד.

● מה מקבלים בסוף הריצה

קובץ אחד עם שורה לכל גישה: כמה פעמים התמלאה, כמה זוגות נסגרו, ותוצאה מחושבת. אין הכרזת מנצחת — זהו רק מפגש אימון קצר כדי לראות איך כל גישה מתנהגת.

בקרהקבועה תמיד, 2 סנטכמות מילויים, זוגות שנסגרו, תוצאה מחושבת
תוקפניתצמודה לשוק, עד 3 סנט

נסו לקרוא את הטור מלמעלה למטה: מלמעלה — מתמלאת הכי מהר, מלמטה — כמעט לא מתמלאת. זו הנקודה, כי בלי מילוי אין עסקה בכלל — מורד הרחוק מדי קונה אפס.

תזכורת בכנות: מילויים כאן מחושבים, הריצה קצרה, וכל גישה קוראה את השוק ברגע קצת שונה. זו תמונה ראשונה, לא ממצא סטטיסטי.

● איך בודקים את זה במערכת עצמה

  2. הריצו python -m scripts.shadow_tournament --minutes 15 --dashboards
    תראו: חמש חלונות נפתחות, אחת לכל גישה. לא לוחצים START.
  3. פתחו http://localhost:8801 ועד 8805

  4. אחרי הריצה, פתחו את קובץ התוצאות שהודפס
    תראו: חמש שורות, אחת לכל גישה, עם ספירות ותוצאה מחושבת.
