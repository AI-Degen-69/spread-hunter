skip: outside quote window

המצב החדש

כל סיבת דילוג וציטוט שמוצג בדשבורד ובפלט הטריידר משתמשת עכשיו במילים של חלון הציטוט — הטווח המרבי שמותר בין מחיר השוק לציטוט שלנו. אין יותר "reward window", "reward minimum", או "score N".

הפונקציה reward_score() נמחקה לחלוטין — כי לא היה לה כבר שום שימוש.

מה לצפות לראות: בלוג הדילוגים בדשבורד ובפלט הטריידר — סיבות כמו "outside quote window", "quote window truncated", "below venue minimum".

איך לאמת בצעדים פשוטים

הרץ את מסלול הצל / הציטוט וקרא את מחרוזות הסיבה:

  1. הרץ מסלול צל קצר: python -m core_brain.shadow_run --minutes 2 --db data/test_shadow.db. תראה שורות דילוג ביומן הסטנדרטי.
  2. בלוג הדילוגים — חפש "quote window" ו-"venue minimum". לא אמור להיות "reward window", "reward minimum", "reward quote", או "score N".
  3. בפלט הטריידר בדשבורד (לשונית Trader) — כל הסיבות מתחת ל-"Skip reasons" משתמשות בשפה של חלון הציטוט.
  4. בדיקת כתיב מהירה: git grep "reward window" -- core_brain/ tests/ צריך להחזיר שורות אפס.
