Kept on purpose

  • “Ladder” meant two different things here. The retired experiment priced short crypto windows in steps — that hall is gone. The price-depth ladder (the stack of bids sitting in the order book) is a different machine entirely, still alive and untouched. Only the experiment ended.
  • The experiment’s guide page stays — docs/explanations/btc-eth-ladder-strategy.html — now wearing a red banner that says the strategy was retired. It records a decision, and decisions stay readable.
  • Old records still say “ladder_exit”. Databases from past runs keep that label on old closes, so the accounting keeps reading it. Nothing historical was rewritten.
