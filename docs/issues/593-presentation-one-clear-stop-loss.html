One clear stop-loss — practice matches real

When the bot ends up holding just one side of a two-sided bet, it now cuts the loss on a single rule you choose — and a practice run makes the exact same call as a real one.

Both runs read the same single rule — they always agree. Only how the trade is actually filled differs between practice and real. (Example assumes a leg bought at 50¢, so 4¢ down ≈ 8%.)

What changed

Before: two rules watched at once — a dollar rule and a percent rule. Nobody could tell which would fire, and a practice run could disagree with a real one.

Now: exactly one rule is active per run. You pick dollar or percent. Practice and real always decide the same way.

The dollar number is simply how much room before cutting: a bigger number means the bot waits longer (and can lose more); a smaller one cuts sooner. The named settings just pick a room size — "conservative" cuts the earliest (3¢ of room), "aggressive" gives the most room (6.5¢).

See it in your setup

Open your trading settings and set the stop mode to percent (the setting HUNTER_STOP_LOSS_MODE), then start a practice session. Watch a naked leg: it now holds or cuts based on the percent drop — the same way a real run would. Switch it back to dollar to use the cents rule.

No screen for this one — it runs inside the trader. Verified automatically by the project's checks (one-rule, practice-matches-real, and tunable), and the full test suite passed on the change.
