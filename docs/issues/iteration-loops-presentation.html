Four improvement rounds

The control room now tells you what is really happening.

Small changes removed four kinds of guesswork: where a report is reading, whether old data can still be found, why a report failed, and whether missing telemetry means “quiet” or “broken.”

ROUND 1 OF 4
Round 1 · Find the right record

A report no longer depends on where you launched it.

Before, the queue report could look empty simply because it was opened from another folder.

Now It always looks in the project’s own shadow store. Same report. Same data. No guessing about the current folder.

What is clearer now

  • Reports find the same shadow data from any launch location.
  • Older market lists remain readable during a folder change.
  • Failures name themselves instead of looking like empty results.
  • Broken telemetry says UNKNOWN on the screen.

What did not change

  • Live controls still require their existing protection.
  • These updates do not place, cancel, or merge orders.
  • A rehearsal is still a rehearsal, not trading performance.

The proof is on the real dashboard: open the alternate local screen, read the shadow badge, and watch the telemetry state explain itself.
