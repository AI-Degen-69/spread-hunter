המצב החדש

כל הרכיבים — ציטוטים, מסלול צל, והגנת single-buy — קוראים מ-BookProvider אחד. אם הסטרים חם: המחיר נקרא מהזיכרון. אם הסטרים קר: נפול לבקשת HTTP אחת ומדווח על כך. אין עוד 520ms מתים לפני כל ציטוט.

מה לצפות לראות: ריצת צל עם סטרים פעיל — ציטוטים מהירים, ללא השהיה נראית. ריצת צל עם --book-source rest — נפול ל-REST, ניתן לזיהוי בלוג.

איך לאמת — ריצת צל עם ובלי סטרים

  1. סטרים פעיל: הרץ python -m core_brain.shadow_run --minutes 5 --db data/test_ws.db. צפה ביומן — שורות ציטוט מופיעות מהר, ללא השהיות 500ms+. אין הודעת "REST fallback".
  2. REST כפוי: הרץ python -m core_brain.shadow_run --minutes 5 --db data/test_rest.db --book-source rest. ביומן תופיע הודעת fallback לכל ספר שנבקש.
  3. השווה: ריצת סטרים — ציטוטים מהירים ויציבים. ריצת REST — ספרות גדולות יותר בשניות המחזור, הודעות fallback נראות.
  4. ריצה בפועל: הפעל את הסטאק המלא, פתח http://127.0.0.1:8799, לשונית Trader — בדוק שמחירי הציטוט מתעדכנים בזמן אמת.
