הוראה חסרת סיכוי: מבטלים — ואז שואלים את הזירה מה באמת התמלא

לפני: ביטול הסתמך על רישום מקומי מיושן, ומילוי של הרגע האחרון נעלם. עכשיו: אחרי כל ביטול שואלים את הזירה, ומילוי חשוף עובר לטיפול במקום להישכח.

מהי הוראה חסרת סיכוי?

הבוט מרוויח מקניית UP + DOWN בפחות מ־$1.00 ומיזוג ל־$1.00. הוראה בודדת שמחירה + ההצעה הזולה בצד השני ≥ $0.99 לעולם לא תיסגר בזול — השלמתה היא הפסד מובטח. השומר מבטל אותה.

0.78 + 0.25 = 1.03 ≥ 0.99← מבטלים

זה שונה מהוראה בודדת כדאית (עדיין יכולה להיסגר בזול — נשארת), ומפוזיציה חשופה (מניות שכבר התמלאו בלי גידור — הולכת למכירת חילוץ).

איך בודקים במו עיניים במוצר החי

  1. מריצים תרגיל צל: py -3.12 -m core_brain.shadow_run --minutes 5 --db data/NN_shadow_766check.db (שם אמיתי — לא <stamp>)
  2. פותחים http://127.0.0.1:8799 (קודם python -m dashboard.server) → כרטיס הריצה של שומר ההוראות.
  3. מחפשים שורות CANCEL_STRAY בלוג — כל שורה היא ביטול של הוראה חסרת סיכוי.
  4. בודקים Unhedged positions: מילוי מחלון התחרות מופיע שם; 0 מהזירה נשאר בחוץ, בלי אזעקת שווא. Cancelled orders נושא כעת את תשובת הזירה; Remediated positions נשאר ריק כל עוד אין מילוי מאומת ברישום.

אם בריצה מסוימת אין שורות CANCEL_STRAY — השוק פשוט לא ייצר הוראה חסרת סיכוי הפעם. מריצים שוב.
