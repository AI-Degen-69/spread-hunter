1 · מה היה שבור

Guard הסדרים רץ על כל 주문 חי ומסווג כל שורה: זוגות gezunt (registry_paired), legs מנותקים (complementary_detached), strays hopeless/viable. שלושה באגים סיכנו money:

  • זוג healthy עם 3+ שורות תחת pair_id אחד (hedge replacement, partial fill) פורק. Guard סמך רק על len(pair_orders) == 2, więc 3 שורות עם שני tokens הושלכו ל-unpaired_orders וה-welded מחדש כ-strays — naked leg אפשרי.
  • ריתוך התעלם מגודל. כל שני legs מנוגדים tokens עם price סכום ≤ cap רותכו, auch אם sizes 5 vs 8. naked leg רותך ל-real one.
  • Adoption resurrected old pair- id. leg's old id reused, though its sibling gone — welded stray is new pairing.
כל branch חדש default ל"leave the order alone" — kein weld over $1.00, kein naked leg.

2 · מה השתנה (سطح)

לפני

Group spanning both tokens با 3+ rows → dismantled → welded anew → naked-leg risk.

Weld: price sum ≤ cap only → mismatched sizes welded.

Adopt: reused leg's old pair- id.

אחרי

Group spanning both tokens با هر row count → stayed registry_paired. Token rule unchanged: one-token groups stay unpaired (duplicated legs).

Weld: requires exact original_size match within WELD_SIZE_EPSILON = 1e-6. Mismatch → both stay untouched.

Adopt: always mints fresh pair-{uuid}, never reuses old id.
