שורת פקודות למסך המסחר

לפני: כל מעבר עמוד וכל פעולה דרשו עכבר. עכשיו: לוחצים על שני מקשים, מקלידים מילה, והמסך קופץ לאן שצריך.

לנסות כאן — מקלידים, זזים עם החצים, בוחרים עם Enter
Use arrow keys to move. Press Enter to choose. Press Escape to close.
זו הדגמה קטנה. הדבר האמיתי נפתח במסך המסחר עם Ctrl + K (או /).

לפני

בלי עכבר אי אפשר היה לעבור עמוד, לסנכרן מול הזירה, או למצוא שוק פתוח.

עכשיו

מקלידים חלק משם — העמוד, הפעולה או השוק מופיעים, ובחירה אחת מפעילה אותם.

לנסות במסך האמיתי

  1. פותחים את מסך המסחר → לוחצים Ctrl + K → נפתח חלון החיפוש.
  2. מקלידים reports → לוחצים Enter → רואים רק את עמוד הדוחות.
  3. מקלידים חלק מכותרת של שוק → Enter → עמוד הבית נפתח כשהטבלה כבר מסוננת.
