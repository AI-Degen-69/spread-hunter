הדשבורד מראה רווח בדולרים והפסד באחוזים — וזה נכון

שני מספרים, שתי שאלות שונות. העדכון הזה מסביר את ההפרדה במקום לתקן נוסחאות שהיו נכונות כל הזמן.

בדשבורד הופיעו ביחד רווח ממוצע של $0.15 לסגירה ותשואה ממוצעת של −9.75% לעסקה. נראה סותר? בעצם כל מספר שוקל את אותן עסקאות אחרת. נסו בעצמכם למטה — הסירו את העסקה הקטנה עם ההפסד הגדול באחוזים, וראו איך האחוזים קופצים בעוד הדולרים בקושי זזים.

המספר החדש — תשואה משוקללת-דולרים: אותם אחוזים, אבל כל עסקה נשקלת לפי הכסף שהיא השקיעה. תמיד מסכים בסימן עם סרגל הדולרים.

מה שונה בפועל

  1. כלום לא תוקן במתמטיקה. הבדיקה הוכיחה ששתי הנוסחאות עושות בדיוק את מה שכתוב עליהן.
  2. סימן שאלה קטן (?) הופיע ליד המספרים בדשבורד — לחיצה עליו מסבירה במשפט אחד למה דולר ואחוז יכולים לחלוק בסימן.
  3. מתחת לאחוזים מופיעה עכשיו התשואה משוקללת-הדולרים — האחוז שמסכים עם סימן הדולרים.
  4. ליד ספירת העסקאות רשום כמה מהן בכלל נמדדו באחוזים — עסקה בלי עלות ידועה נשארת "לא נמדדה", אף פעם לא אפס מזויף.

🕹️ לראות את זה בעבודה האמיתית

  1. פתחו את הדשבורד החי: הריצו .\scripts\spread-hunter-menu.ps1 start ופתחו http://127.0.0.1:8799.
  2. עברו לטאב Analytics וחפשו את "Average Profit Per Close" — לידו מחכה סימן שאלה. לחצו עליו.
  3. מתחת ל־"Mean Return Per Trade" תראו את השורה dollar-weighted; וב־"Executed Sample Size" — כמה עסקאות measured.
  4. ב־run בלי עסקאות שנמדדו באחוזים — במקום אפס תראו "unmeasured".
