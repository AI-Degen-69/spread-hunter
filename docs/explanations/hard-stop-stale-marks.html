1 · How a hard-stop exit is supposed to work

One book, one price: decide and exit on the same fresh snapshot.

Fresh poll bookbid = 0.13
→
Decisionbid ≤ 0.15 → HARD_STOP
→
Exit at fresh bid10 × 0.13 = $1.30
→
ClosePnL = 1.30 − 2.40 = −$1.10

2 · What actually happened

The stop triggers on the fresh book — but the exit prices from a ~13-minute-old snapshot.

Fresh poll bookbid = 0.13 → HARD_STOP ✓
→
Exit reads stale snapshotlast recorded bid = 0.24
→
Close books stale price10 × 0.24 = $2.40 → PnL $0.00
The tell: both exhibits sat ~13 minutes between their last recorded DOWN-book row and the exit — H1 21:08→21:21, H2 20:38→20:51 — while the lifecycle decision saw the live bid (0.13 / 0.15).
