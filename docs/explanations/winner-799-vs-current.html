Why today looks less profitable — four compounding causes

1 · Window, not regression.

Interim 6.4h caught the hot start (H1 mean +$0.199/trade). The full run added 90 cooler closes (H2 +$0.092). Same bot, longer day, lower average.

2 · New filters cost volume.

Queue 3m + balanced band ANDed = fewer quotes than either alone (#843 “volume starvation” hypothesis). queue-5m already traded −49%. 3m is stricter and unmeasured; 89% of queue movement is cancels, so most refused books read “infinite” clear time.

3 · New stop + lockout change exits.

NONE → 4.5¢ absolute stop cuts orphans earlier (2¢ fired 44% in #799; 8–9¢ bled). Plus cf71630a hard-stop lockout (900s) blocks re-entry — the old run re-entered bun-stu-moe 4 min after stopping out.

4 · Ruler + venue changed.

926984be annualised Sharpe — old proxy vs new Sharpe don’t compare. 2ac776b8 Data API v2 + Protocol V2, 2b1aa33f/5afb1556 hedge-on-dropped-markets, 2a14ea05 range telemetry — all post-date #799.
