LIVE-STATE LANGUAGE — THE WATCHDOG VOCABULARY
RUNNING · 3s DEGRADED · 22s DOWN · 74s STOPPED --
The RUNNING dot blinks at 1 Hz (absence of motion reads as death from across the room; honors prefers-reduced-motion). Heartbeat age is displayed, not implied, and ages green → amber → red on a per-service cadence ramp (5s loop: amber ≥ 15s, red ≥ 60s).
BACKEND-CONTACT WATCHDOG — STALE BANNER
⟳ DATA STALE — dashboard lost contact with :8799 last seen 19:15:02 · 42s ago
When polls fail, the page freezes every live tile at its last value with a last-seen age instead of silently continuing to show old numbers. Broken-looking beats lying.
