נסו בעצמכם בדשבורד האמיתי

  1. הפעילו את המחסנית: .\scripts\spread-hunter-menu.ps1 start (או python -m dashboard.server) ופתחו בדפדפן את http://127.0.0.1:8799.
  2. גללו אל כרטיס Orders & Trades ועמדו על לשונית Active Markets.
  3. חפשו את עמודת CATEGORY — היא מופיעה מיד אחרי עמודת השוק. תגית קטגוריה מתחת לשם השוק = תקלה.
  4. לחצו פעמיים על כותרת CATEGORY: פעם ראשונה מיון A→Z, פעם שנייה Z→A.
  5. ודאו שאין עמודת EDGE, וש-24H VOLUME מציג סכום דולר בלבד — בלי שורה כמו 3.2d.
  6. הביטו בגובה השורות: שמות שווקים נכנסים בשורה אחת, והכותרות נשארות קריאות.
  7. עברו גם ל-Orders, Open Positions ו-Closed Trades — עמודת CATEGORY שנייה בכולן. ב-Closed Trades פתחו שורת LEDGER: עליה להגיע עד קצה הטבלה, בלי קיצוץ.
בדיקת הבעלים היא ידנית בלבד: מסך, לחיצה, תוצאה. כל הבדיקות האוטומטיות רצו ברקע כחלק מהעדכון ועברו.
