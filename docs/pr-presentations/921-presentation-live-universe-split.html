סף אחיד של 35 אלף דולר מחק שוקים חיים אמיתיים (כמו ספורט אלקטרוני עם ~13 אלף דולר), ובאותו זמן שוקים שסומנו ״חיים״ אבל לא נסחרו בהם כבר דקות — חדרו פנימה כרוחות רפאים.

⚖️ מה השתנה

שני מסלולי קבלה נפרדים: מסלול חי מהיר וסלחן, ומסלול רגיל קפדן שדורש תנועה אמיתית. זרוע יכולה לבחור: רק חי, רק לא־חי, או תערובת.

זרועות בוחרות צד

שני מתגים חדשים מחלקים את הזרועות למגרשים: BOT_MARKET_LIVE_ONLY_ON — רק שוקים חיים; BOT_MARKET_EXCLUDE_LIVE_ON — רק שוקים לא־חיים. בלי המתגים — תערובת כרגיל. שני המתגים יחד — לא נבחר דבר.

👁️ לבדוק בעצמכם באפליקציה החיה

  1. פתחו: הריצו python -m core_brain.shadow_run --minutes 5 --db data/NN_shadow_i919.db (החליפו NN בראשי התיבות שלכם).
  2. פעולה: הביטו ברשימת המועמדים שהתקבלו מול הנדחים בלוג.
  3. תוצאה: שוקים חיים אמיתיים (ספורט/אי־ספורט, ~13 אלף דולר) מתקבלים; שורות ״חיות״ שהעסקה האחרונה בהן עתיקה מ־300 שניות — נדחות; ספרים שטוחים עם יחס פעילות מתחת 1.5% — נדחים.
  4. מסך נוסף: הריצו python -m dashboard.server, פתחו http://127.0.0.1:8799 ובדקו שכרטיסי הפרמטרים מציגים את ערכי ברירת המחדל החדשים.
